# LOCO — تطبيق Flutter (أندرويد)

نفس لعبة LOCO الموجودة على الموقع، كتطبيق جوال. يتصل بنفس السيرفر (Flask + Socket.IO) المنشور على Render،
فاللاعب على التطبيق يلعب مع لاعب على الموقع والعكس.

**DESIGNED BY EL-GRINGO**

## المميزات

- لعب أونلاين: إنشاء غرفة، الانضمام برمز، نسخ الرمز
- اللعب ضد الكمبيوتر (سهل / متوسط / صعب لا يُهزم) ويمكن الانتقال إليه وأنت تنتظر لاعباً
- إعادة اللعبة برسالة تأكيد، وأونلاين تحتاج موافقة الخصم، وتأكيد قبل الخروج من لعبة جارية (زر الرجوع في الهاتف أيضاً)
- دردشة نصية فورية مع صوت وإشعار عند وصول رسالة وعدّاد للرسائل الجديدة
- دردشة صوتية اختيارية (WebRTC) مع كتم الميكروفون والسماعة، وتعمل بين شبكات مختلفة عند ضبط TURN على السيرفر
- وضع داكن / فاتح / حسب الهاتف، عربي / إنجليزي مع RTL، موسيقى ومؤثرات وتحكم في الصوت
- اللوجو مرسوم بالكود (حاد دائماً)، وأيقونة التطبيق وشاشة البداية مجهزتان
- الموسيقى تتوقف عندما يذهب التطبيق للخلفية وأثناء المكالمة

## المتطلبات

- Flutter **3.27 أو أحدث** (تحقق: `flutter --version`) و Android Studio مع Android SDK
- `flutter doctor` يجب أن يُظهر Android toolchain بعلامة صح

## الإعداد (مرة واحدة)

1. فك الضغط، وافتح الترمنال داخل مجلد `loco_app`.
2. شغّل:
   ```
   powershell -ExecutionPolicy Bypass -File setup.ps1
   ```
   هذا السكربت ينشئ ملفات أندرويد، ويحمّل الحزم، وينشئ الأيقونة وشاشة البداية، ويضيف صلاحيات الإنترنت والميكروفون واسم التطبيق.
3. ضع عنوان Render في `lib/config.dart` (السطر `kDefaultServerUrl`)، أو اتركه وأدخله من التطبيق نفسه (زر السيرفر في أسفل الشاشة الرئيسية).

## التجربة وبناء الـ APK

```
flutter run
flutter build apk --release --split-per-abi --no-shrink
```

الملف الناتج (للأجهزة الحديثة 64-bit):
`build\app\outputs\flutter-apk\app-arm64-v8a-release.apk`
انسخه للهاتف وثبّته (يلزم السماح بالتثبيت من مصدر غير معروف).
إن أردت ملفاً واحداً يعمل على كل الأجهزة: `flutter build apk --release` (حجمه أكبر).

## ملاحظات مهمة

- **السيرفر:** لازم ترفع نسخة `app.py` المحدّثة (فيها تعديل صغير في `leave_game`) إلى GitHub ثم Render، وإلا فالخروج من الغرفة من التطبيق لن يُسجَّل في السيرفر.
- **Render المجاني ينام:** أول اتصال بعد فترة قد يحتاج حتى دقيقة. التطبيق يعيد المحاولة تلقائياً.
- **المكالمة بين شبكات مختلفة** تحتاج TURN على السيرفر (مفاتيح Cloudflare أو Metered في متغيرات Render، كما في دليل الموقع). بدونه تعمل على نفس الشبكة فقط.
- الإشعارات تظهر داخل التطبيق فقط. إشعارات الخلفية (والتطبيق مغلق) تحتاج خدمة إشعارات (FCM)، وهي خطوة لاحقة.
- الـ APK الموقّع بمفتاح التطوير مناسب للتجربة والمشاركة. للنشر في Google Play يلزم مفتاح توقيع خاص.
